# Dynamic Form Layout System

This system allows you to define form layouts using JSON-like configurations that can be easily generated by code generators or defined manually.

## How It Works

### 1. Define Form Config

Create a form config file in `config/forms/` (e.g., `articlesFormConfig.ts`):

```typescript
import { FormConfig } from '../../types/formConfig'

export const articlesFormConfig: FormConfig = {
  width: 100,
  box: [
    {
      label: 'Article Detail',
      width: 100,
      fields: [
        { field: 'title', width: 100 },
        { field: 'author', width: 50 },
        { field: 'language', width: 25 },
        { field: 'status', width: 25 },
        { field: 'content', width: 100 },
      ],
    },
    {
      label: 'SEO Meta',
      width: 100,
      fields: [
        { field: 'meta_title', width: 100 },
        { field: 'meta_description', width: 100 },
      ],
    },
  ],
}
```

### 2. Layout Calculation

Fields are arranged in rows, fitting up to 100 width units:
- `50 + 50` = fills one row
- `50 + 25 + 25` = fills one row
- `33 + 33 + 34` = fills one row
- If total > 100, wraps to next row

### 3. Use in Detail Page

#### Option A: Use GenericDetailForm (Simplest)

```typescript
import GenericDetailForm from '../../components/forms/GenericDetailForm'
import { articlesFormConfig } from '../../config/forms/articlesFormConfig'

export default function ArticleDetail() {
  const router = useRouter()
  const { id } = router.query

  return (
    <GenericDetailForm
      id={id}
      endpoint="/articles"
      isNew={id === 'new'}
      formConfig={articlesFormConfig}
      initialData={{ title: '', content: '', author: '', language: 'en', status: 'draft' }}
      onRenderField={(field, formData, onChange) => {
        if (field.field === 'content') {
          return (
            <textarea
              value={formData[field.field] || ''}
              onChange={(e) => onChange(e.target.value)}
              rows={8}
              className="w-full px-3 py-2 border border-[color:var(--border)] rounded-lg"
            />
          )
        }
        // Default input for other fields
        return null
      }}
      title="Article"
      subtitle="Manage article details"
    />
  )
}
```

## Width Units

- `100` = full width (w-full)
- `75` = 3/4 width (w-3/4)
- `50` = 1/2 width (w-1/2)
- `33` = 1/3 width (w-1/3)
- `25` = 1/4 width (w-1/4)

## Field Rendering

### Default Behavior
Without custom rendering, all fields render as text inputs.

### Custom Field Types
Create custom field renderers for:
- `textarea` - for long text
- `select` - for dropdowns
- `checkbox` - for boolean flags
- `date` - for date pickers
- `number` - for numeric inputs

## Integration with Code Generators

The FormConfig structure is designed to accept JSON from code generators:

```json
{
  "width": 100,
  "box": [
    {
      "label": "Basic Info",
      "width": 50,
      "fields": [
        { "field": "name", "width": 100 },
        { "field": "email", "width": 100 }
      ]
    }
  ]
}
```

Simply import and use this JSON as your FormConfig.

## Example Configs

All form configs are stored in `config/forms/`:
- `articlesFormConfig.ts`
- `cmsUserFormConfig.ts`
- `roleFormConfig.ts`
- `permissionFormConfig.ts`

Each can be modified independently without changing the underlying components.
