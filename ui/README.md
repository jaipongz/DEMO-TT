# UI (Next.js) for TEMPLATE-NEST

This folder is a starter Next.js frontend for the `api/` Nest backend.

Quick start

1. cd ui
2. npm install
3. copy `.env.local.example` to `.env.local` and set `NEXT_PUBLIC_API_URL` if needed
4. npm run dev

The dev server runs on port 3001 by default to avoid colliding with `api/`.
